# Қарағаш

Соцсеть для фото и видео: посты, подписки, заявки в друзья и переписка только между друзьями.

## Структура

- `index.html` — сайт «Қарағаш» (один файл, без сборки).
- `media-vault/index.html` — отдельная медиатека: загрузка, просмотр и скачивание фото и видео. Работает полностью в браузере, сервер не нужен.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com (например, `karagash`).
2. Загрузите все файлы из этой папки в корень репозитория (Add file → Upload files).
3. Откройте Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Важно: что работает на GitHub Pages

- `media-vault/` работает на GitHub Pages сразу.
- `index.html` (соцсеть) использует общую базу данных, вход пользователей и хранилище файлов платформы claude.ai. На GitHub Pages этих сервисов нет, поэтому страница покажет сообщение о недоступности входа. Для работы вне claude.ai нужен собственный бэкенд (например, Firebase или Supabase): Auth для регистрации, база для постов, подписок, заявок и сообщений, хранилище для фото и видео.
